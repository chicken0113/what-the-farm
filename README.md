# What The Farm

현재 개발 대상은 다시 **Unity 6 (6000.3.25f1)** 프로젝트입니다. 작업 폴더는 `C:\Users\MSI\what-the-farm`입니다. Unity 6 기반 3D 게임 프로젝트입니다. 기본 3D 템플릿과 Universal Render Pipeline(URP)을 사용합니다.

## 시작하기

1. Unity Hub에서 이 폴더를 **Add project**로 등록합니다.
2. Unity **6000.3.25f1**로 엽니다. 첫 실행 시 패키지 가져오기에 시간이 걸릴 수 있습니다.
3. `Assets/Scenes/FirstFarm.unity`를 열고 **Play**를 누르면 편집 가능한 첫 농장 맵을 플레이할 수 있습니다. 기존 `FarmPrototype.unity`는 기능 확인용으로 남아 있습니다.

## 첫 맵 배치하기

`Assets/Prefabs/Blockout`의 프리팹을 Project 창에서 Scene 창으로 드래그해 배치합니다. 첫 맵에는 기본 지면, 넓은 경작 가능한 지면, 물가, 다리, 상점과 판매소, 지역 출구를 배치했습니다. 도형의 색과 모양은 배치 용도를 구분하기 위한 임시 표현입니다.

| 프리팹 | 구분 / 용도 |
| --- | --- |
| Ground_Block | 회녹색 지면. 기본 크기 4m × 4m |
| Path_Block | 베이지색 길. 기본 크기 2m × 2m |
| Water_Block | 파란색 물가 표시. 이동을 막지 않음 |
| Bridge_Block | 갈색 다리 바닥 |
| Fence_Block | 갈색 울타리. 기본 길이 2m |
| Rock_Block / Tree_Block | 회색 바위 / 짙은 초록색 나무 장애물 |
| Shop_Block / Sell_Block | 노란 상점 / 주황 판매소 위치 표시 |
| RegionExit_Block | 보라색 다음 지역 출구 위치 표시. 첫 스테이지 공격 모드의 상인 처치 후 E로 이동 |
| SpawnMarker_Block | 청록색 시작 위치 표시 |
| BuyerNPC | 판매 NPC. E 대화, Q로 던진 아이템을 골드로 환전 |

- Play를 끈 상태에서 이동·회전·크기를 조절하고 씬을 저장합니다. 블록의 원점은 바닥 기준입니다. Ground_Block의 X/Z 크기를 늘려 넓은 바닥으로 사용하세요. 별도 밭 블록은 필요하지 않습니다.
- `FirstFarm`에 배치된 시작 위치 표시를 옮기면 플레이어 시작 위치도 바뀝니다. 다른 표시를 사용하려면 **Farm Prototype > Player Spawn Point**에 해당 Transform을 연결합니다.
- **Farm Prototype > Tilling Radius**에서 괭이 한 번에 갈리는 반경(m)을 조절합니다. 기본값은 0.8m입니다. 괭이로 갈아 만든 영역 하나당 대상 하나를 심습니다. 영역 안에서 조준한 위치에 심으며 중앙으로 고정하지 않습니다.
- **Farm Prototype > Inventory Slot Count**에서 인벤토리 칸 수를 조절합니다.
- 상점·판매소 건물·물가·지역 출구는 배치용 표시입니다. 판매소 앞 BuyerNPC는 판매가 가능합니다. 진열 아이템은 E로 골드를 지불해 구매합니다. 물 보충은 아직 연결되지 않았습니다. 지역 출구는 공격 모드의 상인을 처치한 뒤 E로 사용합니다.
- 첫 맵은 100m × 100m이며 울타리를 제거했습니다. 작물 이동 범위는 X/Z ±49.2m입니다. 이전 농장 경계인 X/Z ±13m를 넘으면 기존 상인 NPC가 공격 모드로 전환됩니다. 별도 몬스터는 생성하지 않습니다.
- `What The Farm > Create First Farm Blockout` 메뉴로 초기 배치를 다시 생성할 수 있습니다. 재생성은 첫 맵과 프리팹을 덮어쓰므로 편집한 맵은 다른 이름으로 저장해 보관하세요.

## 시제품 조작

| 키 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 변경 |
| Shift | 달리기 |
| E | 물건을 인벤토리에 집기 / 선택한 아이템 심기 / NPC 대화 / 출구 이용 |
| Q | 조준 방향으로 선택한 아이템 던지기 / NPC에게 던져 판매 |
| 1~9 / 마우스 휠 | 핫바 칸 선택 |
| Tab | 인벤토리 열기 / 닫기 |
| 마우스 왼쪽 | 맨손·괭이로 밭 갈기 / 물뿌리개로 물 주기 / 작물 때리기 |
| Esc | 인벤토리 닫기 / 마우스 잠금 해제 |

빈손 또는 빈 핫바 슬롯에서는 화면 오른쪽 아래에 임시 로우폴리 손이 보입니다. 아이템을 들면 손을 숨기고, 심거나 던져 빈손이 되면 다시 표시합니다. 맨손으로 땅을 조준해 왼쪽 클릭하면 주먹 크기에 맞춘 반경 0.08m(지름 약 16cm)로 밭을 갈 수 있습니다. **Farm Prototype > Bare Hand Tilling Radius**에서 맨손 반경을 별도로 조절합니다. 괭이는 기존 기본 반경 0.8m와 크기 배율을 사용합니다.

바닥은 처음에 전부 갈리지 않은 상태입니다. 괭이를 들고 지면을 보고 왼쪽 클릭하면 가리킨 지점 주변만 불규칙한 외곽선의 진한 갈색 흙으로 바뀝니다. 모양은 경작할 때마다 무작위로 만들어지며 최대 반경과 식재 판정 범위는 그대로입니다. Ground의 **Soil Surface > Till Edge Variation**에서 외곽선 변화량을 조절합니다(기본 0.3, 0이면 원형). 바닥 블록 전체는 바뀌지 않습니다. 갈린 범위 밖에는 심을 수 없으며, 갈린 영역 하나에는 대상 하나만 심을 수 있고, 심을 때 가리킨 지점에 작물이 놓입니다. 이미 심어진 영역에 다시 심으려 하면 아이템은 소비되지 않습니다. 심을 때 기존 작물은 조준을 가리지 않으며, 길과 장애물은 조준을 막습니다. 물을 준 영역은 푸른 흙으로 바뀌고 수확 후에는 갈색으로 돌아옵니다. 길·다리·물가·장애물 표면은 갈 수 없습니다. `E`로 물건을 여러 개 집어 인벤토리에 넣고, 숫자키나 마우스 휠로 핫바 아이템을 선택합니다. `Tab`으로 인벤토리를 열어 아이템 칸을 차례로 클릭하면 이동하거나 서로 교환할 수 있습니다. 갈린 빈 밭에 선택한 물건을 `E`로 심으세요. 기본 설정에서는 심은 뒤 물뿌리개로 밭이나 작물을 보고 왼쪽 클릭해야 성장이 시작됩니다. 물이 이미 있는 땅에서는 바로 시작할 수 있습니다. 오브젝트별 설정에서 물 주기 시작 조건을 끌 수 있습니다. 심은 물건은 원래 모델·색·크기를 유지하며, 바닥에 닿는 높이에 놓입니다. 성장은 심을 때의 크기와 비율을 유지하며, 빛·물·땅 조건에 맞는 보너스가 최종 크기에 반영됩니다. 성장 중 몸집이 커져 주변 식물과 겹쳐도 주변 식물이나 다른 오브젝트는 제거되지 않습니다. 자란 작물은 플레이어를 피해 도망갑니다. 작물을 때려 수확한 뒤에는 다시 심을 수 없으며, 커진 크기로 사용하거나 판매합니다. 인벤토리 칸 수는 Unity에서 `FarmPrototype.unity` 씬의 **Farm Prototype** 오브젝트를 선택한 뒤 Inspector의 **Inventory Slot Count**에서 변경할 수 있습니다. 처음 9칸까지 핫바로 사용합니다. 이 장면은 **로컬 1인 시제품**이며 멀티플레이는 아직 연결되지 않았으며, FirstFarm에서는 공격 모드의 상인 처치 후 다음 지면 씬으로 이동할 수 있습니다.

시작 지점에는 삽 머리·물뿌리개·씨앗을 각각 하나씩 진열합니다. 돌과 중복 씨앗 진열은 제거했습니다. 진열 아이템을 `E`로 구매하면 구매가만큼 골드를 차감하고 원래 위치에 즉시 재입고합니다. 골드 부족이나 인벤토리 가득 참 상태에서는 차감·획득·재입고가 모두 발생하지 않습니다. 일반 드롭, 잡초와 이미 구매한 아이템을 다시 줍는 동작은 무료이며 재고를 추가하지 않습니다. 시작 골드가 없다면 잡초를 상인에게 팔아 구매 자금을 마련할 수 있습니다.

## 오브젝트별 성장 조건

성장률은 **최종 크기**에 적용됩니다. 성장 속도는 환경 보너스의 영향을 받지 않습니다.

`최종 크기 성장률 = 기본 100% + 맞는 빛 조건의 보너스 + 맞는 물 조건의 보너스 + 맞는 땅 조건의 보너스`

예를 들어 빛 +20%, 물 +30%가 맞으면 150%이며, 기본 100% 완성 크기의 1.5배가 됩니다. 조건이 맞지 않으면 해당 보너스만 빠집니다. 성장 도중 환경을 다시 확인하고 완성 시점의 조건으로 최종 크기가 결정됩니다.

### 오브젝트 설정

- `Assets/Data/Growth`에 씨앗·수확물·괭이·물뿌리개·돌의 예제 설정과 기본 설정이 있습니다. 파일을 선택하고 Inspector에서 수치를 변경하세요.
- 새 설정은 Project 창의 **Create > What The Farm > Plant Growth Profile**로 만듭니다. 오브젝트 프리팹의 **Farm Item > Growth Profile**에 연결하면 오브젝트마다 다른 조건을 사용할 수 있습니다.
- 얻을 수 있는 임의 모델에도 FarmItem과 Collider/Rigidbody를 연결하고 Growth Profile을 지정해 같은 성장 시스템을 사용할 수 있습니다. 종류별로 별도 성장 코드를 작성할 필요는 없습니다.
- 현재 자동 생성하는 아이템은 씬의 **Farm Prototype > Growth Profiles**에 연결한 설정을 사용합니다. 목록에 없는 종류는 **Default Growth Profile**을 사용합니다.
- 수확 후 아이템과 재고 보충에도 해당 설정이 유지됩니다. 수확물로 종류가 바뀌어도 원래 오브젝트의 성장 조건을 이어받습니다.

| Inspector 항목 | 의미 |
| --- | --- |
| Base Rate Percent | 기준 최종 크기 성장률. 기본 100 |
| Growth Seconds / Seconds Per Generation | 성장 시간 / 세대당 추가 시간 |
| Mature Size Multiplier / Size Per Generation | 100% 조건의 완성 크기 배율 / 세대당 추가 배율 |
| Require Water To Start | 물을 받은 뒤 성장 시작. 해제하면 마른 땅에서도 시작 |
| Use Light Condition / Min Light / Max Light / Light Bonus Percent | 빛 조건 사용 여부, 선호 범위, 맞으면 더할 % |
| Use Water Condition / Min Water / Max Water / Water Bonus Percent | 물 조건 사용 여부, 선호 범위, 맞으면 더할 % |
| Use Soil Condition / Preferred Soils / Soil Bonus Percent | 땅 조건 사용 여부, 선호 땅 종류, 맞으면 더할 % |

### 땅과 환경 설정

- Ground_Block의 자식 Ground에 붙은 **Soil Surface**에서 Soil Type, Light Amount, Initial Water Amount를 지정합니다. 빛과 물의 기준 범위는 0~100입니다.
- `Assets/Data/Soils`에는 Loam(일반 흙), Clay(점토), Sand(모래), Paddy(논), Jungle(정글)의 예제 종류가 있습니다. **Create > What The Farm > Soil Type**으로 종류를 더 만들 수 있습니다.
- **Sunlight**에 Directional Light를 연결하면 세기와 실제 장애물의 그늘을 계산합니다. Full Sun Intensity는 기준 태양 세기, Shade Light Amount는 그늘의 수치입니다. 비워 두면 Light Amount를 그대로 사용합니다. 첫 맵은 태양에 연결되어 있습니다.
- 물뿌리개는 **Farm Prototype > Water Per Use**만큼 물의 양을 늘립니다. 기본값 25, 최대 100이며 여러 번 물을 줄 수 있습니다. 선호 범위를 넘으면 물 보너스를 받지 못합니다.
- Initial Water Amount는 새로 갈아 만든 영역의 초기 물 양입니다. 플레이 중 갈린 영역의 Farm Plot > Water Amount에서 현재 양을 확인할 수 있습니다.
- 갈린 영역 하나당 대상 하나, 조준 위치에 심기, 원래 외형·크기 유지 규칙은 계속 적용됩니다.

## 판매 NPC

첫 맵 판매소 앞 `(9, 0, 7.5)`에 BuyerNPC를 배치했습니다. 가까이서 NPC를 보고 `E`를 누르면 대사가 순서대로 출력됩니다. 수확한 작물 또는 다른 아이템을 핫바에서 선택하고 NPC를 향해 `Q`로 던지면 받는 범위에 들어간 아이템이 사라지고 골드가 지급됩니다. 성장 중인 대상이나 도망다니는 작물은 먼저 수확해서 아이템으로 만든 뒤 판매합니다. 씨앗·수확물·도구·물뿌리개·돌 모두 판매할 수 있습니다.

- 기본 판매가는 아이템에 표시된 골드 값입니다. 화면 오른쪽 위에 보유 골드가 표시됩니다.
- BuyerNPC의 **Npc Merchant > Display Name / Dialogue / Dialogue Seconds / Sale Multiplier**에서 이름, 대사, 표시 시간, 가격 배율을 변경합니다.
- **Sphere Collider > Radius**는 아이템을 받는 범위입니다. Capsule Collider는 몸의 충돌과 대화 조준에 사용됩니다.
- 다른 곳에 NPC를 추가하려면 BuyerNPC 프리팹을 배치합니다. World 참조가 비어 있으면 현재 씬의 Farm Prototype을 찾습니다.
- 보유 골드는 현재 플레이에만 유지되며, **Farm Prototype > Starting Gold**에서 초기 금액을 설정합니다.

## 유니티 복귀 및 첫 스테이지

- 개별 아이템은 한 번만 심을 수 있습니다. 수확한 아이템은 커진 크기를 유지하며 사용하거나 판매할 수 있습니다. 다른 새 아이템은 빈 밭에 심을 수 있습니다.
- 기본 아이템 크기를 약 30%로 줄였습니다. 떨어진 아이템끼리 또는 플레이어·상인과 몸으로 충돌하지 않으며, 지면 충돌과 E 줍기·NPC 판매는 유지합니다. Layer 8은 LooseItem, Layer 9는 FarmCharacter입니다.
- 공급품을 주우면 같은 X/Z 위치의 바닥에 새 재고가 즉시 배치됩니다.
- FirstFarm의 Farm Prototype에 **Farm First Stage**를 연결했습니다. Original Half Size가 상인의 공격 모드를 발동시키는 경계입니다. Merchant에 상인 NPC를 지정할 수 있으며, 비워 두면 씬의 상인을 찾습니다. 첫 스테이지 경계 규칙은 다음 씬에는 적용하지 않습니다.

### 플레이어 시체 부활 준비

Farm Prototype의 **Player Revival Requires Planting**을 켜면 사망한 플레이어는 즉시 복귀하지 않고 조작이 중지됩니다. 다른 LocalFarmer가 시체를 주워 경작지에 심으면 하체를 묻은 상태에서 원래 시체 주인의 실제 체력을 회복합니다. 물주기는 필요 없으며 최대 체력에 도달하면 해당 위치에서 부활합니다. 인벤토리는 유지합니다. **Player Revival Healing Seconds**로 회복 시간(기본 4초)을, **Player Plant Buried Fraction**으로 매장 비율(기본 0.5)을 설정합니다. 현재 플레이어에게 전신 모델이 없어 플레이어 시체는 임시 캡슐 모델입니다. 기본값은 꺼져 있어 1인 플레이에서는 기존 즉시 복귀를 사용합니다.

NPC와 플레이어 시체는 PlantableCorpse에 원래 대상 참조와 OwnerId를 보존하며 식재 시 복제하지 않습니다. 로컬 두 플레이어 검증으로 소유자별 부활을 확인합니다. 네트워크 접속, 서버 권한, 사망/인벤토리/체력 회복 상태 동기화와 접속 종료 처리는 아직 구현하지 않았습니다. 실제 온라인 협동 부활은 멀티플레이 연결 시 이 처리를 서버에 연결해야 합니다.

MerchantSMG.prefab은 기존 총기 모델과 기존 URP 무기 머티리얼을 참조하며 총의 충돌체는 제거했습니다. 총기 음원은 추가하지 않았습니다. **MerchantSMG.prefab > Npc Firearm > Bullet Speed**로 탄속(기본 18m/s), **Bullet Max Distance**로 최대 비행 거리(기본 30m)를 조절합니다. 탄속을 낮추면 피하기 쉬워집니다. 총기 프리팹 재구성 메뉴는 **What The Farm > Configure Merchant Firearm**이며 맵이나 캐릭터 모델을 재생성하지 않습니다.

아이템을 심으려면 현재 크기와 심어진 자세 기준의 가로·세로 범위가 마우스로 지정한 위치에서 경작지 안에 모두 들어가야 합니다(가장자리 여유 5mm). 작은 밭이나 가장자리에 걸치는 위치에서는 거부하며, 들고 있는 아이템과 식재 이력은 변경하지 않습니다. 높이는 비교하지 않고 바닥에 필요한 면적을 비교합니다. 일반 아이템·도구·NPC/플레이어 시체에 공통으로 적용합니다. 불규칙한 흙 그림의 모양 대신 저장된 경작 반경을 기준으로 판정합니다.

삽(Hoe.prefab)은 이전 버전의 2배로 확대했습니다(처음 크기 대비 3배, 완성 모델 높이 약 0.81m). 새로 획득·재입고되는 삽은 원본 모델에서 분리한 삽 머리만 표시하고 경작·공격에 사용할 수 없습니다. 빈손으로 같은 빈 경작지를 반복해서 파면 반경이 한 번에 4cm씩 넓어지며, 두 번 파면 커진 기본 삽날을 심을 수 있습니다. 식물이 있는 밭은 확장할 수 없습니다. 삽 머리를 심으면 전체 삽 모델을 땅속에 묻어 삽날만 지상에 보이게 합니다. 삽은 성장 중 크기를 키우지 않고, 진행도에 맞춰 모델 전체를 위로 올려 손잡이가 점차 드러납니다. 물을 주고 다 키운 뒤 때려 수확하면 사용 가능한 삽이 되며, 삽의 원래 크기와 크기에 비례하는 경작 범위를 유지합니다. 일반 식물·아이템의 크기 성장은 그대로 유지하며, 모든 대상의 성장 완료 시 색상 변경은 제거했습니다. GrowableTool 컴포넌트가 머리/전체 모델 전환을 담당하고, ShovelHead.asset은 기존 Unity 삽 메시의 머리 부분입니다. 맵이나 원본 에셋은 재생성하지 않았습니다.

다 자란 삽은 플레이어를 추적하고 근접 공격합니다. 기본 감지 거리 8m, 이동 속도 2.5m/s, 공격 거리 1.25m, 피해 10, 준비 동작 0.3초, 공격 후 대기 1.2초입니다. 준비 중 뒤로 물러나면 피할 수 있으며 고체 장애물은 이동·공격 경로를 막습니다. 수확하면 공격을 중단하고 사용 가능한 삽 아이템이 됩니다. 다른 식물은 기존 도주 방식을 유지합니다. **Hoe.prefab > Growable Tool**의 Aggro Range, Chase Speed, Attack Range, Attack Damage, Attack Interval, Attack Windup에서 조절합니다.

간단한 1인칭 동작은 FarmActionAnimation의 절차적 애니메이션으로 구현했습니다. 아이템을 주우면 앞으로 뻗었다 돌아오고, 심기는 아래로 내밀기, 물주기/사용은 기울이기, 빈손 좌클릭은 주먹을 앞으로 내지르기, 아이템 좌클릭은 뒤로 당긴 후 대각선으로 휘두르기입니다. 같은 카메라 하위 피벗이 손과 아이템 그립을 움직이며 카메라 위치/조준·아이템 크기는 변경하지 않습니다. 슬롯 전환 시 기본 자세로 복귀합니다. 성장한 삽의 공격은 뒤로 젖히기 → 몸 전체 휘두르기 → 0.22초 복귀이며 Growable Tool의 Attack Windup/Attack Recovery로 시간을 조절합니다. 전용 AnimationClip 없이 동작하며 기존 선택형 Animator 훅도 유지합니다.

### 아이템 구매 / 판매 가격 도구

유니티 상단 **What The Farm > Item Prices**를 열어 구매가와 기본 판매가를 변경하고 **저장**을 누릅니다. 씨앗, 수확물, 기본 괭이, 삽 머리, 완성된 삽, 물뿌리개, 돌/잡동사니, NPC 시체, 플레이어 시체를 모두 포함합니다. 검색과 목록 새로 확인 기능이 있으며 기존 가격을 덮어쓰지 않습니다. 가격 데이터는 `Assets/Resources/ItemPrices.asset`에 저장합니다. NPC와 플레이어 시체도 판매할 수 있으며, 판매하면 해당 시체는 소비됩니다.

판매액은 **기본 판매가 × 세대별 판매가 배율^Generation × 상인의 Sale Multiplier**입니다. 세대 배율도 창에서 변경합니다. 최종 금액은 정수로 반올림합니다. 0골드로 설정한 아이템도 판매 시 소비됩니다. 손에 든 아이템·심어진 대상·이미 판매된 아이템은 판매되지 않으며, 평화 상태인 상인에게 Q로 던진 아이템만 환전됩니다. 구매가는 즉시 재입고되는 진열 아이템을 E로 구매할 때 바로 적용됩니다. 일반 바닥 드롭은 무료로 줍습니다.

새 아이템은 FarmItem의 **Custom Price Id**에 고유한 ID를 지정하고 창에서 **아이템 목록 새로 확인**을 누르면 별도 가격 행이 추가됩니다. 빈 ID는 기본 종류별 가격을 사용합니다. 사용자 지정 ID는 성장·수확 후에도 유지합니다. 단순 장식 오브젝트와 수집할 수 없는 총기 모델은 거래 아이템이 아닙니다.
### 자연 생성 잡초

잡초는 SoilSurface가 있는 지면의 무작위 지점에 생성됩니다. 첫 스테이지에서는 상인의 경계 이탈 공격 판정과 같은 안전 구역 안에서만 생성되며 경계에서 0.5m 안쪽에 여유를 둡니다. 기본 안전 구역은 맵 중심 기준 X/Z ±13m이므로 생성 위치는 ±12.5m 안쪽입니다. Farm First Stage의 Original Half Size를 바꾸면 잡초 생성 범위도 함께 바뀝니다. 갈린 밭에서도 생성되며 자연 발생 잡초는 밭의 식재 칸을 차지하지 않습니다. 물가·건물·장애물 위나 다른 아이템·작물과 겹치는 위치는 피합니다. 녹색 풀 모양이며 E로 주워 Q로 상인에게 던져 판매합니다. 물주기나 때려 수확하기 없이 즉시 수집할 수 있습니다.

`Assets/Resources/WeedSpawning.asset`에서 Enabled, Interval Seconds(기본 20초), Initial Count(12), Count Per Interval(3), Max Wild Weeds(60), Minimum Spacing(0.6m), Placement Attempts(32)를 조절합니다. Farm Prototype의 Weed Spawning에 별도 설정을 지정하면 해당 맵만 다른 설정을 사용할 수 있습니다. 빈 값은 위 공통 설정을 사용합니다. 잡초를 주우면 자연 잡초 수 제한에서 빠져 다음 주기에 새 잡초가 생성될 수 있습니다. `Assets/Resources/Weed.prefab`에서 모양을 바꿀 수 있습니다.

잡초도 갈린 빈 밭에 심을 수 있으나 크기·모델·판매가가 변하지 않고 성장·공격·도주하지 않습니다. 직접 심은 잡초는 식재 칸을 차지하며, E로 다시 주우면 해당 칸을 비웁니다. 기존 아이템처럼 한 번 심은 잡초의 재식재는 제한됩니다. **What The Farm > Item Prices**의 잡초 행에서 가격을 조절합니다(기본 판매가 3골드).

### 가격 도구의 성장 시간

**What The Farm > Item Prices**에서 기본 판매가 오른쪽의 **성장 시간 (초)**를 설정합니다. 5를 입력하면 성장 시작 후 5초에 다 자라고, 10은 10초입니다(최소 0.1초, 기본 4초). 세대별 추가 시간 없이 입력한 시간을 그대로 사용합니다. 물주기 등 성장 시작 조건과 최종 크기에 대한 환경 보너스는 유지합니다. 성장 중 수정하면 현재 진행률은 유지하고 남은 성장에 새 시간을 적용합니다. 삽은 **삽 머리 (심기 전)** 행에서 시간을 조절합니다. 완성된 삽은 성장 완료, 잡초는 성장 없음, NPC/플레이어 시체는 체력 회복으로 표시합니다. 시체의 회복 시간은 기존 Farm Guardian / Farm Prototype 설정에서 조절합니다. 가격과 성장 시간 모두 기존 ItemPrices.asset에 함께 저장합니다. 가격 목록에 없는 아이템은 기존 성장 프로필의 시간을 사용합니다.

줍기/던지기/판매 메시지의 아이템 이름은 FarmItem.DisplayName을 공통으로 사용합니다. WeedGreen.mat은 URP Lit 셰이더와 녹색 _BaseColor를 사용합니다.

인벤토리와 핫바는 이름 대신 현재 아이템의 실제 모델 썸네일을 표시합니다. 숫자 단축키와 선택 칸 표시는 유지합니다. 삽 머리와 완성된 삽은 각각 현재 모양으로 표시되며, 도구·작물·잡초·몸체도 같은 방식으로 렌더링합니다. 썸네일은 처음 표시할 때 생성하고 캐시하며, 아이템을 버리거나 플레이어가 제거되면 해제합니다.

썸네일 생성은 LocalFarmer.LateUpdate에서 수행하고 OnGUI에서는 캐시된 이미지만 그립니다. URP 렌더링 중 중첩 렌더 요청으로 생기는 UniversalCameraData 오류를 방지합니다. Farm Prototype의 **Tool Tilling Range Multiplier**(기본 0.5)로 삽 경작 반경을 조절할 수 있습니다. 기존 반경의 절반이며, 삽 크기에 따른 정비례는 유지합니다.
